# 📝 Python To-Do List App

A simple command-line To-Do List app written in Python.  
It allows users to add, view, mark as done, and delete tasks using a menu-driven interface.

## 📂 Features
- Add new tasks
- View tasks with their status
- Mark tasks as done
- Delete tasks

## 🚀 How to Run
1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal or command prompt.
4. Run the app by typing:
   ```bash
   python todo_app.py
```
